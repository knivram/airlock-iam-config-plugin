Fills an empty Airlock plugin id: with a freshly generated UUID.

Offered on Alt+Enter when the caret is on a plugin definition's id: (an id: whose mapping also has a type:) that has no value yet. Plugin ids are opaque — usually UUIDs — so this saves typing one by hand.

Only applies in Airlock IamConfig files, and never to a property literally named id (e.g. a step's properties.id).
