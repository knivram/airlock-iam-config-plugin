Reports a known-type plugin that omits a property the Airlock IAM catalog marks as mandatory. The missing property is reported as an error on the plugin's type:.

A quick-fix, Add missing mandatory properties, inserts the missing keys under the plugin's properties: mapping (creating properties: when absent), each with an empty value ready to fill in.

Reported as an error and enabled by default. Only plugin types known to the catalog are checked.

Note: in Airlock IAM mandatory-ness is sometimes conditional (a property is only required given some other setting). The mandatory flag is taken from the documentation, so a few properties that are only conditionally required may still be reported.
