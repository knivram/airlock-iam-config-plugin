Reports a property the bundled Airlock IAM plugin catalog marks sensitive (such as a password or secret) whose value is a literal plain-text string committed into the config.

Externalized and obfuscated forms are not flagged: a configuration variable (var:), an external secret (storageId:), a [FILE] reference, or an [OBFUSCATED] value. Only properties of plugin types known to the catalog are checked, so custom or unrecognised plugins never produce false positives.
