Reports misconfigured configuration variables (var:) and environment/value entries in Airlock IAM config files.

A property value can be a list of entries, each carrying exactly one value form (value/valueList/plugin/pluginList/pluginMap) plus optional env/context selectors and a var block ({name, sensitive}). This inspection flags, within a single file:

  • a var: block without a name, or with keys other than name/sensitive, or a non-boolean sensitive;
  • two value entries that share the same environment/context (only one would ever apply);
  • a value entry with no value form, or with more than one;
  • an unexpected key inside a value entry.

A value list without a shared (env-less) default entry is legal and is not flagged.
